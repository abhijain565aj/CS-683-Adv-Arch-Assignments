\section{Task 1B: Stride Pattern Prefetcher (SPP)}

\subsection{Design Requirements}
The L1D SPP should classify per-IP accesses into uniform constant-stride behavior and repeating non-uniform stride sequences. Uniform-stride prediction should be prioritized, with transition or fallback to non-uniform prediction when warranted. The implementation should maintain a stride-history signature for non-uniform patterns, support a degree greater than one, use accuracy-based throttling, and keep requests within the same OS page.
