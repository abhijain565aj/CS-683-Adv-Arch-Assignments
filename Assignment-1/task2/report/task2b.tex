\section{Task 2B: SIMD (Single Instruction Multiple Data)}

\subsection{SIMD Implementation}
To parallelize the SGEMM operation, we implemented a register-blocked SIMD micro-kernel using AVX2 intrinsics. We unrolled the outer loops to compute a $2 \times 4$ block of the output matrix $C$ simultaneously. For the inner dot-product loop across the $K$ dimension, we used \texttt{\_mm256\_loadu\_ps} to fetch 8 elements from both matrices and accumulated the results using \texttt{\_mm256\_fmadd\_ps}. Finally, we implemented a \texttt{horizontal\_sum} helper function using vector extraction and addition to collapse the 8-lane accumulators into scalar values for the final output. 

\subsection{Performance and Instruction Analysis}

The SIMD/register-blocked implementation substantially reduced the number of executed instructions. For a $1024 \times 1024$ matrix, the baseline executed $\sim$6.46 billion instructions, whereas the 256-bit implementation required only $\sim$227 million---a reduction of roughly $28\times$. This reduction reflects the complete micro-kernel: vector operations, the $2 \times 4$ register block, unrolling, load reuse, FMA, and less loop-control work.

\subsection{Questions}

\begin{enumerate}
    \item \textbf{What trends do you observe in speedup for different combinations of matrix sizes and SIMD widths?} \\
    The 256-bit SIMD implementation outperforms the 128-bit implementation in these measurements. For both widths, the speedup is highest at smaller sizes (for example, $12.64\times$ at $N=128$) and declines at $N=2048$ ($10.00\times$ for 256-bit). This trend suggests that data delivery and cache effects become a larger fraction of execution time as the matrix footprint grows.
    
    \item \textbf{For which SIMD width do you achieve the maximum speedup?} \\
    We achieved the maximum speedup using the 256-bit SIMD width. It produced a geometric-mean speedup of roughly $11.19\times$ across the tested sizes. AVX2 processes 8 single-precision values per vector instruction, twice the 4 values of 128-bit SIMD; realized throughput also depends on loads, execution ports, dependencies, and frequency.
\end{enumerate}
